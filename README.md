## Inoffizielle Filterliste: ÖIAT Watchlist Internet (Liste betrügerischer Shops)

Dieses Repository erzeugt automatisch eine AdGuard-Home-Filterliste oder auch Pi-hole-Filterliste aus der öffentlichen Liste des Österreichischen Instituts für angewandte Telekommunikation (ÖIAT) / Watchlist Internet: https://www.watchlist-internet.at/liste-betruegerischer-shops/
Die Daten werden aus dem CSV-File der Liste übernommen: https://www.watchlist-internet.at/liste-betruegerischer-shops/csv/

### Link zum Filterliste: https://raw.githubusercontent.com/AlexPhBit/OEIAT-Watchlist-Internet---Filter/refs/heads/main/filter.txt
